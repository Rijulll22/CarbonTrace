WHAT IS CARBONTRACE?
────────────────────
CarbonTrace is a GHG Protocol-aligned carbon accounting and verification
prototype. It enables companies to:

  1. Record and calculate carbon emissions from business activities
     (deterministically: emissions = activity_quantity × emission_factor)
  2. Store emissions in a PostgreSQL database with full traceability
  3. Cryptographically verify records using a SHA-256 hash-chain ledger
  4. Optimize reduction pathways under a budget using linear programming (PuLP)
  5. Explain emissions data in plain language using an LLM (explanation only)

IMPORTANT SCOPE LIMITATIONS (What CarbonTrace does NOT currently do):
  - It does NOT parse PDFs, Excel files, or CSV documents
  - It does NOT use OCR or document extraction
  - The Upload / Document Processing / Extracted Review screens are
    VISUAL/STATIC PROTOTYPE screens only — they do not process real documents
  - There is NO live blockchain deployment. The Solidity contract
    (blockchain/CarbonRetirement.sol) is a static code artifact only.
  - There is NO carbon credit retirement workflow
  - This is NOT a statutory compliance tool and NOT third-party assured
  - Do NOT claim regulatory certification during the presentation

Position CarbonTrace as: "a GHG Protocol-aligned prototype"

This creates:

  - 3 demo suppliers (Supplier A, B, C)
  - 10 carbon activity records with deterministic emissions
  - 10 SHA-256 hash-chain ledger entries

TROUBLESHOOTING COMMON PROBLEMS
================================================================================

PROBLEM: Dashboard shows loading spinner / error banner
─────────────────────────────────────────────────────────
  CAUSE:   FastAPI backend not running, or database not seeded
  FIX 1:   Check that uvicorn is running (Step 2)
  FIX 2:   Run seed: Invoke-WebRequest -Uri http://127.0.0.1:8000/api/v1/seed -Method POST -UseBasicParsing
  FIX 3:   Check PostgreSQL is running (Step 1)

PROBLEM: Frontend shows "Failed to fetch" or network error
──────────────────────────────────────────────────────────
  CAUSE:   Backend on wrong port, or CORS issue
  CHECK:   Is backend running on port 8000?
           Test-NetConnection localhost -Port 8000
  FIX:     Restart backend with exactly:
           ..\\.venv\Scripts\uvicorn.exe main:app --port 8000
           (run from backend\ directory)

PROBLEM: PostgreSQL fails to start
───────────────────────────────────
  CAUSE:   Another PostgreSQL process already running
  FIX:     Check task manager for postgres.exe processes and kill them first
  CHECK:   Test-NetConnection localhost -Port 5432

PROBLEM: npm run dev fails
──────────────────────────
  FIX:     cd D:\Buildonomics\CarbonTrace\frontend; npm install
           Then: npm run dev

PROBLEM: Optimizer returns 422 error
─────────────────────────────────────
  CAUSE:   target_reduction_percentage is 0 or > 100
  FIX:     Use a value between 0.01 and 100 (e.g. 10)

PROBLEM: Verification screen shows "No ledger entries"
───────────────────────────────────────────────────────
  CAUSE:   Database not seeded yet
  FIX:     POST /api/v1/seed (see Step 5)

PROBLEM: AI explanation shows fallback message
──────────────────────────────────────────────
  CAUSE:   No API key configured (OpenRouter or OpenAI)
  NOTE:    This is EXPECTED in demo mode. The fallback message is intentional.
  FIX:     Add OPENROUTER_API_KEY or OPENAI_API_KEY to backend/.env

STOPPING THE APPLICATION AFTER THE DEMO
================================================================================

In each PowerShell window, press Ctrl+C to stop the running process:

  Window 1 (PostgreSQL):   Ctrl+C
  Window 2 (FastAPI):      Ctrl+C
  Window 3 (npm dev):      Ctrl+C

To reset the demo database for a fresh run:
  1. Stop the FastAPI server
  2. Run: & "D:\INFOSEC PROJECT\.pgsql\bin\psql.exe" -U postgres -c "DROP DATABASE IF EXISTS carbontrace;"
  3. Run: & "D:\INFOSEC PROJECT\.pgsql\bin\psql.exe" -U postgres -c "CREATE DATABASE carbontrace;"
  4. Restart FastAPI (it will recreate tables on startup)
  5. POST /api/v1/seed again
